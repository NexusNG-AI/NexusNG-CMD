NexusNG-CMD is an AI-powered command-line interface that provides real-time responses using the DeepSeek API. Created by TucoT9, this modern and interactive CLI tool offers a unique experience with animated text, live previews, and the ability to manage multiple chats.

## 🚀 Features

- 🤖 **AI-powered responses** using the DeepSeek API
- 💻 **Modern command-line interface** with a smooth user experience
- ✨ **Animated text and live previews** for enhanced interaction
- 💬 **Multi-chat management**: Easily create and switch between multiple conversations
- 💾 **Local chat storage**: All chat histories are stored securely on your machine
- 🔒 **Secure API key management** to protect your credentials
- ⚙️ **Customizable settings** to fit your needs

## 📥 Installation

### 1️⃣ Clone the repository
```sh
git clone https://github.com/T9Tuco/NexusNG-CMD.git
cd NexusNG-CMD
```

### 2️⃣ Install dependencies
```sh
pip install -r requirements.txt
```

### 3️⃣ Run the application
```sh
python nexusng_cmd.py
```

## 🛠️ Usage

When you first run NexusNG-CMD, you'll be prompted to enter your **DeepSeek API key**. If you don't have one, follow the instructions below to obtain it.

### Available Commands:
1. **Start a new chat**
2. **Continue an existing chat**
3. **List all saved chats**
4. **Access settings**
5. **Exit the application**

### In the settings menu, you can:
- View your chat storage location
- Change your preferred name
- Delete all your stored data

## 🔑 Obtaining a DeepSeek API Key

To use NexusNG-CMD, you need a DeepSeek API key. Here's how to get one:

1. Visit [DeepSeek](https://www.deepseek.com/)
2. Sign up for an account or log in
3. Navigate to the **API section** in your dashboard
4. Generate a new API key
5. Copy and store the key securely

_⚠️ Note: DeepSeek may have different pricing tiers. Check their pricing and terms of service before use._

## 🗄️ Data Storage

NexusNG-CMD stores your chat histories and settings **locally** in the `.nexusng_chats` directory in your home folder. No data is sent to external servers (except to DeepSeek for AI responses).
