# NexusNG-CMD

NexusNG-CMD is an AI-powered command-line interface that provides real-time responses using the DeepSeek API. Created by TucoT9, this modern and interactive CLI tool offers a unique experience with animated text, live previews, and the ability to manage multiple chats.

## Features

- 🤖 AI-powered responses using the DeepSeek API
- 💻 Modern command-line interface
- ✨ Animated text and live previews
- 💬 Create and switch between multiple chats
- 💾 Local storage of all chat histories
- 🔒 Secure API key management
- ⚙️ User settings and preferences

## Installation

1. Clone the repository:
   \`\`\`
   git clone https://github.com/TucoT9/NexusNG-CMD.git
   cd NexusNG-CMD
   \`\`\`

2. Install the required dependencies:
   \`\`\`
   pip install -r requirements.txt
   \`\`\`

3. Run the application:
   \`\`\`
   python nexusng_cmd.py
   \`\`\`

## Usage

When you first run NexusNG-CMD, you'll be prompted to enter your DeepSeek API key. If you don't have one, you'll need to obtain it before using the tool.

Once you've entered your API key, you can use the following options:

1. Start a new chat
2. Continue an existing chat
3. List all chats
4. Access settings
5. Exit the application

In the settings menu, you can:
- View your chat storage location
- Change your preferred name
- Delete all your data

## Obtaining a DeepSeek API Key

To use NexusNG-CMD, you'll need a DeepSeek API key. Here's how to get one:

1. Visit the DeepSeek website at https://www.deepseek.com/
2. Sign up for an account or log in if you already have one
3. Navigate to the API section of your account dashboard
4. Generate a new API key
5. Copy the API key and keep it secure

Note: DeepSeek may have different pricing tiers or plans. Make sure to review their pricing and terms of service before purchasing an API key.

## Data Storage

NexusNG-CMD stores your chats and settings locally on your machine. By default, they are saved in the \`.nexusng_chats\` directory in your home folder.
